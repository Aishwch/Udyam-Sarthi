# Udyam Sarthi — Industrial Symbiosis MVP

An MVP for matching industrial by-products/waste with resource requirements from other industries.

## Problem
Industries may generate useful by-products while other industries need similar materials. Udyam Sarthi helps discover potential matches using:
- material compatibility
- quantity
- location/distance
- frequency
- application

## Stack
- React + Vite
- Plain CSS
- Demo data
- Deterministic matching engine

## Run
```bash
npm install
npm run dev
```

This is an MVP with demo data. No claim is made that a match is commercially or technically valid without expert verification.
